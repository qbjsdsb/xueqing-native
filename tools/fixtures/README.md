# Fictional Fixtures

All shared development fixtures must be fictional and non-sensitive.

Spike target datasets may include approximately:

- 10 organizations;
- 100 fictional teachers;
- 1,000 fictional students;
- 10,000+ fictional cases;
- 50,000+ fictional timeline events.

The fixture generator should produce deterministic IDs/data from a seed where useful, allowing reproducible performance and sync tests. Do not derive fixtures from production exports.
