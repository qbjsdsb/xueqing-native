# Domain Contracts

Machine-readable or implementation-neutral representations of stable Xueqing domain semantics belong here once formats are chosen.

Initial domain vocabulary:

- Organization / Membership / App User / Identity Link
- Subject / Student / Enrollment / Student Subject Profile
- Student Teacher Assignment
- Learning Case / Case Event
- Evidence / Intervention / Assessment
- Case Action
- Operation Receipt / Audit

Do not create contract schemas merely to mirror UI DTOs.
